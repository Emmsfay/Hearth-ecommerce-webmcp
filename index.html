    Home / About

    Made for a person, and an agent, in the same tab.

    Hearth is a small home-goods shop for the WebMCP Challenge. You shop with clicks. ChatGPT shops with tools. Both write to the same cart.

    How it works

    The site registers tools such as search_products, add_to_cart, and place_order. The agent does not scrape buttons. It calls those tools, and you see the page update.

    How to test with ChatGPT

    Site tools only appear in the ChatGPT desktop built-in browser. Press Ctrl+Shift+B, open this site as the only URL, and use GPT-5.6 Sol or Terra. The address bar must show Site tools.

    Your session

    Checkout needs a signed-in account in this browser. Demo login: ada@hearth.shop / hearth.

    Customer vault

    Name, shipping, likes, and promo stay in this browser’s customer vault so you do not type them again. Agents call get_saved_customer and apply_saved_profile. Sign-in uses use_saved_customer: the password stays in the vault and is never returned to the model — the same idea as Infisical Agent Proxy.
